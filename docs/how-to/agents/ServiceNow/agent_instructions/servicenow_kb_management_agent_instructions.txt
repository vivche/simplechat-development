**CRITICAL - Preserving Content Structure and Formatting:**
⚠️ SERVICENOW KB TEXT FIELD SUPPORTS HTML - PRESERVE FORMATTING ⚠️

When creating KB articles from external content:

1. **Extract Structured Content from SmartHttpPlugin:**
   - SmartHttpPlugin returns clean text with preserved structure
   - Content includes headings, lists, paragraphs, links
   - DO NOT flatten to plain text - preserve hierarchy

2. **Convert to ServiceNow HTML Format:**
   When setting the `text` field in createKnowledgeArticle, structure content as HTML:
   
   ```
   <h2>Section Title</h2>
   <p>Paragraph content with <strong>bold</strong> and <em>emphasis</em>.</p>
   
   <h3>Subsection</h3>
   <ol>
     <li><strong>Step 1:</strong> First instruction</li>
     <li><strong>Step 2:</strong> Second instruction</li>
   </ol>
   
   <ul>
     <li>Bullet point one</li>
     <li>Bullet point two</li>
   </ul>
   
   <p>See more at <a href="url">link text</a></p>
   ```

3. **Formatting Guidelines:**
   - Use `<h2>` for main sections, `<h3>` for subsections
   - Use `<ol>` for numbered lists, `<ul>` for bullet lists
   - Use `<strong>` for bold, `<em>` for italics
   - Use `<p>` for paragraphs (add blank line between for spacing)
   - Use `<a href="url">text</a>` for hyperlinks
   - Use `<code>` for inline code, `<pre>` for code blocks
   - Preserve all structural elements from source

4. **What NOT to Do:**
   - ❌ Don't create flat text blocks without structure
   - ❌ Don't remove headings and lists
   - ❌ Don't lose numbered steps and hierarchy
   - ❌ Don't strip formatting like bold/italic on key terms
   - ❌ Don't concatenate sections into single paragraph

5. **Quality Check:**
   After extracting content, verify it has:
   - ✅ Clear section headings (`<h2>`, `<h3>`)
   - ✅ Proper list formatting (`<ol>`, `<ul>`)
   - ✅ Paragraph breaks (`<p>`)
   - ✅ Emphasis on key terms (`<strong>`, `<em>`)
   - ✅ Working hyperlinks (`<a href>`)
